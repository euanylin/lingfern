| Area | Current behavior and implementation |
|---|---|
| Navigation and setup | Today / Library / Settings; Introduction previews the application. Setup has four steps and saves directly to Today. Saved interface/navigation modes are prepared before the first client render; Today's fern receives its current lookup count with the surrounding records. HTML 404s use the same App/header and client return navigation while retaining real HTTP error responses. `src/app/App.tsx`, `src/app/initialInterface.ts`, `src/app/FirstRun.tsx`, `src/app/NotFound.tsx`. |
| Practice | Reading, Listening and Combined use the shared task preview and material workspace. Ordinary generation uses eligible local material before automatic download; corpus review scopes are indexed and shards read in bounded parallel batches. Practice and Test reuse the same saved question/material/scoring snapshot; Test withholds assistance and delays feedback. `src/app/prepareCorpusPractice.ts`, `src/data/corpus.ts`, `src/app/TaskDetail.tsx`, `src/app/MaterialWorkspace.tsx`, `src/data/practice.ts`. |
| Generation and teaching | Prepared eligible source text/audio feeds bounded local generation. Source attribution, exclusion/rights holds, exact evidence and teaching coverage remain separate from raw inventory counts. See [teaching coverage](docs/teaching-coverage-matrix.md) and [corpus maintenance](content/corpus/README.md). Rule-based results do not establish CEFR calibration or learning effects. |
| Local data | Dexie/IndexedDB stores profiles, transactional answers, saved sessions, bookmarks and lookup history. The records-only history lists delete a session (including linked parts) or one lookup after concise confirmation, with transactional rollback, retained familiarity and sync tombstones. Backup/import validates bounded data and preserves failure recovery. Bookmarks are save/remove only; vocabulary review scheduling is retired. `src/data/db.ts`, `src/data/deletion.ts`, `src/data/backup.ts`. |
| Offline resources and updates | Same-origin resources, integrity-checked installation and the Service Worker support installed offline practice. Update safety preserves active work and failed-update recovery. `src/data/runtimeResources.ts`, `src/sw.ts`, `src/app/serviceWorkerUpdate.ts`. |
| Language and accessibility | Fourteen dedicated interface packages; reviewed A1–A2 display translations; B1–C2 instruction and About remain English. Arabic navigation is RTL, English learning material LTR. Shared controls preserve keyboard focus, native scrolling, reduced-motion behavior and 44px targets. Filled action feedback is owned by `public/button-feedback.css`, with common pointer/touch/keyboard colours and scaling and no underline. Shared disclosure and control motion retain inert closing contents and reduced-motion alternatives. |
| Reference tools | Local dictionary, grammar and IPA resources; explicit external dictionary links; saved items and lookup history. Dictionary and learning selection lookup read built-in/community entries concurrently; dictionary stars reuse the projected bookmark list. Explicit practice choices share bank/readiness checks only within the current operation. No silent third-party lookup dependency for ordinary offline use. |
| Search metadata | Five unchanged public URLs support fourteen description packages and request-language prerendering. Hydration prepares the document's language before applying saved preferences; identical generated styles are shared. Server/client/offline metadata share canonicals, private/noindex handling and language rules. English is the request fallback; no extra language routes or sitemap/hreflang aliases. Googlebot's usual language-neutral crawl still receives English. `src/shared/seo.ts`, `src/locales/*/seo.json`, `docs/seo.md`. |
| Identity and synchronization | Optional GitHub identity and private-repository synchronization, with account/profile fencing, durable events, bounded retry and idempotent batches. Availability is conditional on configured Worker bindings/secrets and `SYNC_ENABLED`, not permanently disabled. `worker/auth.ts`, `worker/repository.ts`, `src/data/sync*.ts`. |
| MCP and AI handoff | Optional explicitly approved, expiring shared snapshots with ownership/revocation checks; normal share lifetime remains 24 hours. External AI feedback remains a draft and cannot rewrite original answers or formal scores. `worker/mcp.ts`, `worker/oauth.ts`, `worker/sharing.ts`, `src/app/AiHandoff.tsx`. |
| Deployment | One Vite/React frontend and Cloudflare Worker with Static Assets at `https://lingfern.com`. Narrow route fallbacks preserve missing-resource/API errors. Routine publication is local-first with GitHub CI disabled. See [workflow](AGENT_WORKFLOW.md) and [runbook](docs/release-runbook.md). |

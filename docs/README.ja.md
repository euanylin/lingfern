# Lingfern

**[ウェブサイト ↗](https://lingfern.com)**

<img src="../public/icon.svg" width="96" alt="Lingfern">

16 歳以上を対象とした英語のリーディング・リスニング練習。学習目標は A1–C2 に対応し、原文と録音から端末内で練習を生成します。学習にアカウントや AI サービスは必要ありません。

## 使い始める

1. [Lingfern](https://lingfern.com) の紹介を確認し、開始レベルと興味を設定します。
2. [今日](https://lingfern.com/today)で**リーディング・リスニング・総合練習**を選び、プレビューから**練習／テスト**を開始します。総合練習は読解と聴解の両セッションを関連付けて保存します。
3. [資料室](https://lingfern.com/library)で調べものや教材のダウンロード、[設定](https://lingfern.com/settings)で表示・プロファイル・任意の接続を管理します。

<a id="readme-practice"></a>

## 練習とテスト

読解と聴解で目標レベル、トピック、教材、問題形式を個別に指定するか、**自動**を使用します。選択はプロファイルごとに保存されます。教材に応じて、選択、穴埋め、根拠選択、組み合わせ、表、並べ替え、自由回答が出題されます。

| モード | 動作 |
|---|---|
| 練習 | 利用可能な例、3 段階のヒント（目標・手掛かり・言語）、辞書、自己評価。 |
| テスト | 同じ練習内容を使用し、補助と AI を無効化。終了後にフィードバックを表示し、音声の再生・シークは利用可能。 |

客観問題には採点と解説があり、自由回答は自動採点しません。**スキップ／回答を再開**では下書きを保ち、スキップを正解として扱いません。

<a id="readme-workspace"></a>

## 読解・音声の操作

- 原文の語句を選択して辞書で調べる、ハイライトする、教材のメモを保存することができます。
- 解答カードは問題への移動だけを行い、入力を自動で開始しません。モバイルでは解答パネルを展開・リサイズでき、デスクトップでは左右を別々にスクロールできます。
- 現在の録音に対応する全問題・グループを順番に表示します。一時停止、再生、シーク、問題移動でも再生状態と下書きを保持します。
- 下書きは回答中に保存されます。最後の問題の後で提出するか、未完了の練習を再開します。確認後の**やり直し**で練習を置き換えられます。保存エラー時は、ページを離れる前に再試行・復旧・下書きの書き出しを利用してください。

<a id="readme-history"></a>

## 履歴と進捗

今日の[**履歴**](https://lingfern.com/progress)からセッション、回答、フィードバック、使用した補助を確認し、確認操作の後で保存済み回答を削除できます。読解・聴解の目標別進捗を表示し、時刻修正の項目が出た場合は完了時刻を確認できます。

シダは保存された学習活動を表し、認定された能力を示すものではありません。毎日の引用には出典があり、長文の展開と別の引用への切り替えができます。

<a id="readme-library"></a>

## 辞書とブックマーク

| ツール | 機能 |
|---|---|
| [英英辞典](https://lingfern.com/library/dictionary) | 単語を検索して英語の定義を表示。読解中に選択した語句も検索できます。 |
| [ブックマーク](https://lingfern.com/library/saved) | ★／☆ で定義を保存・解除し、項目を折りたたみ。解除した項目は再表示・更新まで残るため、すぐに戻せます。 |
| [IPA 発音表](https://lingfern.com/library/ipa) | 簡易／詳細表示、発音記号検索、用意されている音声と英語の例語。 |
| [英語用法辞典](https://lingfern.com/library/grammar) | キーワード検索、アルファベット順の閲覧、説明の展開。 |
| [検索履歴](https://lingfern.com/library/history) | 種類、日時、保存された検索状態から、辞書・用法・IPA の検索を再表示。 |

外部辞書は Cambridge、Oxford Learner’s Dictionaries、Wiktionary、Merriam-Webster から選択できます。リンク先のサイトで開き、用法の外部検索には Cambridge Grammar を使います。

<a id="readme-offline"></a>

## オフラインとコミュニティ教材

資料室で文章・音声・辞書パッケージを検索、選択、インストール、更新、削除できます。必要な資源をインストールすると、学習・採点・保存・インストール済みの辞書はオフラインで使えます。接続状態の変化は短い通知で表示します。

互換性のあるコミュニティ ZIP を取り込めます。再インストールや別の端末用に元の ZIP を保管してください。ダウンロード、GitHub、MCP、外部サイトは通信が必要で、教材と録音は端末ごとにインストールします。

対応ブラウザーでは「アプリをインストール／ホーム画面に追加」からウェブアプリとして利用できます。

<a id="readme-backup"></a>

## プロファイルとバックアップ

**設定 → バックアップ**でプロファイルを切り替えます。既定の `lingfern-YYYY-MM-DD` または任意の名前で ZIP を書き出せます。この名前は復元後のプロファイル名として ZIP 内にも保存され、外側のファイル名を変更しても内部名は変わりません。

名前と記録件数をプレビューして、別のプロファイルとして取り込みます。本機のプロファイル削除には確認が必要で、他のプロファイルとリポジトリのコピーは残ります。

バックアップにはセッション、回答、下書き、ブックマーク、検索履歴、フィードバック、設定が含まれます。**暗号化されず**、教材パッケージと音声は含まれません。安全に保管し、資源は別途インストールしてください。

<a id="readme-sync"></a>

## GitHub 自動同期

1. 設定で GitHub に接続し、アカウントのプロファイルを選択するか、本機のプロファイルをコピーします。
2. 専用の**非公開**データリポジトリを作成し、GitHub App に権限を与え、設定中に選択・検証します。
3. 学習の要約、ブックマーク、検索履歴、設定、インストールの選択、対応する削除を自動で双方向同期します。オフラインの変更は再接続まで保持します。

同期中・同期済み・オフライン待機・エラーと最終成功時刻を表示します。**今すぐ同期／再試行**、自動同期の停止、設定中のリポジトリ接続解除が可能です。競合の復旧項目が表示されたらデータを書き出せます。完全なセッション・回答・音声は同期されないため、全記録の移動にはバックアップを使います。

**GitHub ID を切断**すると全端末のサイトセッションを終了し、同期の関連付けを無効にし、有効な共有を削除して MCP 接続を解除します。本機の記録とリポジトリのファイルは残ります。GitHub 側の認可解除を確認できない場合は画面の手順に従ってください。ID を切断せず、個別の MCP 共有や接続だけを解除することもできます。

<a id="readme-ai"></a>

## AI への引き継ぎと MCP

- 対応する保存済み回答で、目標、教材／抜粋、問題、回答、フィードバックを選択します。プレビュー後にコピー、Markdown／JSON の書き出し、対応端末のシステム共有ができます。返されたフィードバックを貼り付け・取り込み、確認して別のメモとして保存します。元の回答と点数は変更しません。
- **Streamable HTTP + OAuth** 対応クライアントに `https://lingfern.com/mcp` を設定し、その接続に明示的にスナップショットを共有します。共有は **24 時間**またはそれより早い接続期限で失効し、設定で共有・クライアントを管理・解除できます。許可された共有の検索・閲覧と、別の権限による公開教材要約の検索に対応します。[接続方法とツール（英語）](mcp-clients.md)。

<a id="readme-preferences"></a>

## 言語と表示

14 言語の UI、ライト／ダーク／システム連動、デスクトップとモバイルそれぞれの文字・アイコン・併用ナビゲーション、既定のオンライン辞書、開始レベルと興味の変更、キーボード・タッチ・動きを減らす設定に対応します。

教材の英語は英語のままです。審査済み A1–A2 のガイダンスには翻訳があり、B1–C2 と About は英語です。アラビア語のナビゲーションは RTL、英語の内容は LTR で表示します。

**更新を確認 → 今すぐ更新**で保存済み進捗を保って再読み込みします。About と教材詳細にはプロジェクトのリンク、出典、ライセンスがあります。

<a id="readme-privacy"></a>

## データとプライバシー

記録は現在のブラウザーのサイトストレージに保存されます。サイトデータの消去や端末変更の前にバックアップしてください。GitHub 同期は任意で、完全なバックアップの代わりにはなりません。

広告や既定で有効なテレメトリーはありません。AI が取得するのは選択・共有された情報だけで、個人の全履歴ではありません。解除しても相手が受信済みのコピーは削除できません。結果は課題への取り組みを表し、認定 CEFR レベルや試験得点ではありません。

## ローカル実行と貢献

[`.nvmrc`](../.nvmrc) の Node.js を使い、リポジトリのルートで実行します。

```sh
npm ci
npm run build
npm run preview
```

[ローカルプレビュー](http://127.0.0.1:8787/today)を開きます。本機での学習に GitHub／Cloudflare の認証情報は不要です。

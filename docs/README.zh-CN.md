# Lingfern

**[网站 ↗](https://lingfern.com)**

## 开始使用

1. 打开 [Lingfern](https://lingfern.com)，浏览介绍并设置学习起点与兴趣。
2. 在[今日](https://lingfern.com/today)选择**阅读、听力或综合训练**，在预览中选择**练习或测试**；综合训练保存相互关联的阅读和听力练习。
3. 在[资料库](https://lingfern.com/library)查询、下载资源；在[设置](https://lingfern.com/settings)管理偏好、档案与可选连接。

<a id="readme-practice"></a>

## 练习与测试

分别设置阅读与听力的目标等级、主题、材料及题型，也可保留**自动**。选择按档案保存。题型依材料而定，包括选择、填空、证据选择、匹配、表格、排序和开放回答。

| 模式 | 行为 |
|---|---|
| 练习 | 提供适用的教学示例、三级提示（目标、线索、语言）、词典与自评。 |
| 测试 | 使用同一练习快照，关闭辅助与 AI，完成后显示反馈；保留音频重播和进度跳转。 |

客观题提供对应评分与解释；开放回答不自动评分。**跳过此题／继续作答**保留草稿，不将跳过计为正确。

<a id="readme-workspace"></a>

## 阅读与听力操作

- 阅读原文，选词查词或高亮，保存材料笔记。
- 答题卡只定位题目，不自动进入输入；移动端阅读支持展开、调整答题面板大小，桌面端两栏可独立滚动。
- 听力按原序展示当前录音的全部题组、小题；暂停、重播、拖动进度或跳题时保留播放与草稿。
- 作答时自动保存草稿；最后一题后提交，也可继续未完成练习，或确认**重来**以替换练习。保存失败时，离开前使用提示的重试、恢复或草稿导出功能。

<a id="readme-history"></a>

## 历史记录与进度

从今日进入[**历史记录**](https://lingfern.com/progress)，回看练习、答案、反馈与辅助使用情况，确认后删除已保存的回答；查看阅读、听力目标进度，出现时钟修正选项时确认完成时间。

活动蕨反映已保存的学习活动，不代表认证水平。每日一句标明来源，长文可展开，也可切换另一句。

<a id="readme-library"></a>

## 查询工具与书签

| 工具 | 功能 |
|---|---|
| [英英词典](https://lingfern.com/library/dictionary) | 按词查阅英语释义，也可在阅读中选词查询。 |
| [书签](https://lingfern.com/library/saved) | 用 ★／☆ 保存、取消释义，折叠词条；取消后的词条在重开或刷新前保留，便于立即恢复。 |
| [IPA 发音表](https://lingfern.com/library/ipa) | 简易／详细视图、音标搜索，以及可用的音标录音和英语例词。 |
| [英语用法词典](https://lingfern.com/library/grammar) | 关键词搜索、字母浏览、展开解释。 |
| [查询历史](https://lingfern.com/library/history) | 根据来源、时间与保存的查询状态，重新打开词典、用法与 IPA 记录。 |

可选择 Cambridge、Oxford Learner’s Dictionaries、Wiktionary 或 Merriam-Webster 进行在线查询。链接在对应网站打开，用法查询使用 Cambridge Grammar。

<a id="readme-offline"></a>

## 离线与社区资源

在资料库搜索、选择、安装、更新或移除文章、音频与查询资源包。安装所需资源后，学习、评分、保存与已安装的查询工具均可离线使用；连接变化有短暂状态提示。

可导入兼容的社区 ZIP 材料／资源包；保留原始 ZIP，便于重装或换设备。下载、GitHub、MCP 和外部网站需要联网；资源和录音需在各设备分别安装。

在支持的浏览器中，可通过“安装应用／添加到主屏幕”将 Lingfern 作为网页应用使用。

<a id="readme-backup"></a>

## 档案与备份

在**设置 → 备份**切换档案。导出时可使用默认的 `lingfern-YYYY-MM-DD` 名称或自定义名称；名称同时保存在备份内部，供恢复后的档案使用。手动改 ZIP 文件名不会覆盖内部名称。

导入前预览档案名称与记录数量，恢复为独立档案。删除本地档案需确认，其他档案和远端仓库副本保留。

备份包含练习、答案、草稿、书签、查询历史、反馈与偏好，**未加密**，不含已安装的资源包／音频；请妥善保管，并单独重装资源。

<a id="readme-sync"></a>

## GitHub 自动同步

1. 在设置连接 GitHub，选择账号档案，或复制本地档案到该账号。
2. 创建专用的**私有**数据仓库，为 GitHub App 授权，在配置过程中选择并核验仓库。
3. 自动双向同步学习摘要、书签、查询历史、偏好、安装选择及支持的删除操作；离线修改保留，联网后补传。

卡片显示同步中、已同步、离线待同步或失败及上次成功时间；可**立即同步／重试**、暂停自动同步，或在配置中断开仓库绑定。出现冲突恢复选项时，可导出冲突数据。同步不传输完整练习、答案或已安装音频，完整记录请使用备份。

**断开 GitHub 身份**会结束所有设备的网站会话、停用同步绑定、移除有效分享并撤销 MCP 连接，保留本地记录和仓库文件。若无法确认 GitHub 侧撤销，请按页面提示操作；也可在不断开身份的情况下单独撤销 MCP 分享或连接。

<a id="readme-ai"></a>

## AI 交接与 MCP

- 对支持的已保存回答，选择目标、材料／节选、题目、回答及反馈，预览后复制、导出 Markdown／JSON，或在支持的设备使用系统分享。粘贴或导入返回反馈，审阅后另存；原答案与分数不变。
- 在兼容的 **Streamable HTTP + OAuth** 客户端连接 `https://lingfern.com/mcp`，再明确向该连接分享快照。分享在 **24 小时**或更早的连接到期时失效，可在设置管理、撤销分享与客户端。授权客户端可搜索、读取其分享快照，另获相应权限后可搜索公开材料摘要。见[客户端配置与工具（英文）](mcp-clients.md)。

<a id="readme-preferences"></a>

## 语言与外观

14 种界面语言；浅色／深色／跟随系统主题；桌面与移动端分别选择文字、图标或图文导航；默认在线词典；可调整学习起点与兴趣；支持键盘、触屏及减少动态效果偏好。

英语材料保持英文。经审查的 A1–A2 指导提供翻译支持，B1–C2 指导及关于页面保持英文。阿拉伯语导航从右向左排列，英语内容保持从左向右。

**检查更新 → 立即更新**刷新页面并保留已保存进度。关于和材料详情提供项目链接、来源与许可。

<a id="readme-privacy"></a>

## 数据与隐私

记录保存在当前浏览器的网站存储中，清理网站数据或换设备前请导出备份。GitHub 同步为可选功能，不能代替完整备份。

无广告、不默认收集遥测。AI 仅能获得明确选择或分享的上下文，不能读取私人历史；撤销不能删除其他服务已接收的副本。结果反映任务表现，不是认证 CEFR 等级或考试分数。

## 本地运行与参与项目

使用 [`.nvmrc`](../.nvmrc) 指定的 Node.js 版本，在仓库根目录运行：

```sh
npm ci
npm run build
npm run preview
```

打开[本地预览](http://127.0.0.1:8787/today)。本地学习无需 GitHub／Cloudflare 凭据。

# Lingfern

[网站](https://lingfern.com) · [English](../README.md) · [简体中文](README.zh-CN.md) · [使用指南](user-guide.md)

<img src="../public/icon.svg" width="96" alt="Lingfern">

可以离线使用的英语阅读与听力练习。

Lingfern 面向 16 岁及以上学习者。选择学习目标，阅读英语文章、聆听录音，按自己的节奏练习并回看记录。学习不需要注册账号，也不需要使用 AI 服务。

## 按自己的方式学习

- **阅读、听力或综合训练：**单独练习一项技能，或依次完成阅读和听力。
- **练习或测试：**练习时可以使用提示和词典；测试时不提供辅助，完成后再查看反馈。开放回答不自动评分。
- **保留学习过程：**在历史记录中回看已保存的练习、答案和反馈，将有用的词语加入复习。
- **离线使用：**先在资料库中安装需要的文章、音频和参考资料，再断网学习。
- **选择练习内容：**分别设置阅读、听力的目标、主题、材料和题型，也可以保留“自动”。练习由客户端根据符合条件的原始材料生成。
- **使用参考工具：**查询词义、复习收藏的词语、播放简易或完整 IPA 音标及例词录音、查阅英语用法词典。Cambridge 查询由你主动打开。
- **按需连接：**使用 GitHub 登录、通过选定的私有数据仓库同步，或向外部 MCP 客户端分享指定快照。外部 AI 反馈与原答案、正式评分分别保存。

学习目标覆盖 A1–C2。结果反映具体任务的表现，不是经过认证的 CEFR 等级或考试分数。

## 从哪里开始

| 页面 | 可以做什么 |
|---|---|
| **今日** | 阅读每日一句、设置并开始训练、查看已保存活动对应的蕨类生长状态，以及打开历史记录。 |
| **资料库** | 使用词典、词语复习、IPA 录音及英语用法参考；搜索、安装或移除资源，导入兼容的社区资源包。 |
| **设置** | 选择语言、主题和导航外观，管理档案、备份、GitHub 同步、MCP 授权及应用更新。 |

界面支持简体中文、繁体中文、英语、日语、韩语、法语、西班牙语、德语、葡萄牙语、意大利语、俄语、阿拉伯语、印地语和印度尼西亚语。英语材料保持英文；初学阶段的指导提供翻译支持。B1–C2 学习指导及关于页面使用英文。阿拉伯语导航从右向左排列，英语材料仍从左向右显示。

[使用指南（英文）](user-guide.md)介绍练习、离线使用、备份和可选连接。

## 你的学习数据

练习和答案保存在当前设备的浏览器中。清除网站数据、更换浏览器档案或丢失设备，可能使你无法再访问这些记录。请定期在设置中导出备份，尤其是在换设备或清理浏览器之前。

备份 ZIP 含个人学习数据，没有加密，请妥善保管。已安装的资源包和音频不包含在学习备份中。

GitHub 同步和 AI 分享都可以不用。同步使用你选定的私有数据仓库，网络请求失败不会撤销已经保存的本地答案；MCP 客户端只能访问你明确分享的内容快照，受有效期和撤销控制。登录不要求绑定同步仓库。撤销会停止后续访问，但无法删除外部服务已经取得的副本。Lingfern 没有广告，也不默认收集遥测数据。

## 本地预览与参与项目

本地运行请看[开发指南（英文）](development.md)，其中列有 Node 版本、安装步骤和检查命令。本地学习不需要 GitHub 或 Cloudflare 凭据。

发现问题时，可以[提交 Issue](https://github.com/euanylin/lingfern/issues)，说明操作步骤、预期结果和浏览器信息。请勿附上个人学习记录、备份或凭据。

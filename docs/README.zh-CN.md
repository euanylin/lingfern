# Lingfern

[网站](https://lingfern.com) · [English](../README.md) · [简体中文](README.zh-CN.md) · [使用指南](user-guide.md)

<img src="../public/icon.svg" width="96" alt="Lingfern">

支持在线与离线使用的英语阅读、听力练习。面向 16 岁及以上学习者，学习目标覆盖 A1–C2。学习无需注册账号或使用 AI 服务。

## 功能

| 功能 | 内容 |
|---|---|
| **阅读、听力与综合训练** | 根据原始文章和录音在本地生成练习；设置目标、兴趣、主题、材料和题型。综合训练依次进行阅读与听力。 |
| **练习与测试** | 练习支持示例、三级提示、词典和自评；测试关闭辅助，完成后显示反馈。客观题自动评分，开放回答可以跳过，不自动评分。 |
| **阅读与播放控制** | 高亮原文、保存材料笔记，通过答题卡定位题目；连续查看同一录音的全部题目，暂停、重播或拖动播放进度。 |
| **记录与进度** | 恢复未完成的练习，回看答案和反馈，删除已保存的回答，查看阅读与听力进度及活动蕨。今日页还提供每日一句。 |
| **查询工具** | 英英词典、释义可折叠的书签、带录音的简易／完整 IPA 音标表、英语用法词典，以及三类工具的查询历史；可选择在线查询词典。 |
| **离线资源** | 在资料库搜索、安装、更新或移除资源包；导入包含文章、音频的兼容社区 ZIP。 |
| **档案与备份** | 切换或删除本地档案，自定义备份名称，下载 ZIP，预览并恢复为独立档案。 |
| **GitHub 自动同步** | 连接私有数据仓库，双向同步学习摘要、书签、查询历史、偏好与安装选择；支持离线待同步、状态显示及手动重试。 |
| **可选 AI 交接** | 预览选中的上下文，导出 Markdown／JSON，单独保存返回的反馈；也可向已授权 MCP 客户端分享限时快照，在设置中管理分享与撤销权限。 |
| **个性化** | 14 种界面语言、浅色／深色／跟随系统主题、独立的桌面与移动端导航显示、起点与兴趣设置、应用更新及来源／许可致谢。 |

打开 [lingfern.com](https://lingfern.com)：**今日**用于训练和历史记录，**资料库**用于查询与下载，**设置**用于偏好和连接。具体操作见[使用指南（英文）](user-guide.md)。

界面支持简体中文、繁体中文、英语、日语、韩语、法语、西班牙语、德语、葡萄牙语、意大利语、俄语、阿拉伯语、印地语和印度尼西亚语。英语材料保持英文，A1–A2 指导提供翻译支持；B1–C2 指导及关于页面使用英文。阿拉伯语导航支持从右向左排列。

## 学习数据

学习记录保存在浏览器中。清理网站数据或换设备前请导出备份：ZIP 未加密，不含已安装的资源包和音频。GitHub 同步为可选功能，不能代替完整备份。MCP 客户端只能读取明确分享的快照；撤销权限无法删除对方已经取得的副本。Lingfern 没有广告，不默认收集遥测数据。

学习结果反映任务表现，不是经过认证的 CEFR 等级或考试分数。

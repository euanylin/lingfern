# Lingfern

**[Sitio web ↗](https://lingfern.com)**

<img src="../public/icon.svg" width="96" alt="Lingfern">

Práctica de lectura y comprensión auditiva en inglés para mayores de 16 años, con objetivos de A1 a C2. Los ejercicios se generan localmente a partir de textos y grabaciones. No necesitas una cuenta ni un servicio de IA para aprender.

<a id="readme-start"></a>

## Primeros pasos

1. Abre [Lingfern](https://lingfern.com), consulta la introducción y elige puntos de partida e intereses.
2. En [Hoy](https://lingfern.com/today), selecciona **Lectura**, **Comprensión auditiva** o **Combinado** y, en la vista previa, **Práctica** o **Prueba**. El modo combinado conserva dos sesiones vinculadas.
3. Usa la [Biblioteca](https://lingfern.com/library) para consultar y descargar; [Ajustes](https://lingfern.com/settings), para preferencias, perfiles y conexiones opcionales.

<a id="readme-practice"></a>

## Práctica y prueba

Configura por separado nivel objetivo, temas, materiales y tipos de preguntas, o conserva **Automático**. Las elecciones se guardan por perfil. Según el material hay opción múltiple, huecos, selección de pruebas textuales, emparejamiento, tablas, secuencias y respuestas abiertas.

| Modo | Comportamiento |
|---|---|
| Práctica | Ejemplos, tres pistas (objetivo, indicio, lengua), diccionario y autoevaluación cuando estén disponibles. |
| Prueba | El mismo ejercicio sin ayuda ni IA; comentarios tras finalizar. Permite repetir y desplazarse por el audio. |

Las preguntas objetivas tienen corrección y explicaciones. Las respuestas abiertas no se puntúan automáticamente; **Omitir / Reanudar respuesta** conserva el borrador sin contar la omisión como acierto.

<a id="readme-workspace"></a>

## Lectura y controles de audio

- Selecciona texto para consultar el diccionario o resaltar; guarda notas sobre el material.
- La tarjeta de respuestas localiza preguntas sin activar la entrada. En móvil, el panel de lectura se expande y cambia de tamaño; en escritorio, los paneles se desplazan por separado.
- Se muestran en orden todos los grupos y preguntas de la grabación actual. Pausar, repetir, buscar en el audio o cambiar de pregunta conserva reproducción y borradores.
- Los borradores se guardan mientras respondes. Envía tras la última pregunta, reanuda una sesión incompleta o confirma **Reiniciar** para sustituirla. Si falla el guardado, usa reintento, recuperación o exportación del borrador antes de salir.

<a id="readme-history"></a>

## Historial y progreso

Abre [**Historial**](https://lingfern.com/progress) desde Hoy para revisar sesiones, respuestas, comentarios y ayudas usadas; elimina respuestas guardadas tras confirmar. Consulta el progreso de lectura/escucha por objetivo y confirma horas de finalización cuando aparezca la corrección del reloj.

El helecho representa actividad guardada, no un nivel certificado. Las citas diarias incluyen fuente, expansión de textos largos y selección de otra cita.

<a id="readme-library"></a>

## Consultas y marcadores

| Herramienta | Funciones |
|---|---|
| [Diccionario inglés](https://lingfern.com/library/dictionary) | Consulta de palabras con definiciones en inglés, también desde el texto seleccionado. |
| [Marcadores](https://lingfern.com/library/saved) | ★/☆ para guardar o quitar definiciones y entradas plegables. Lo quitado permanece hasta reabrir/actualizar para poder recuperarlo al instante. |
| [Tabla IPA](https://lingfern.com/library/ipa) | Vistas sencilla/detallada, búsqueda de sonidos, grabaciones y palabras de ejemplo disponibles. |
| [Referencia de uso del inglés](https://lingfern.com/library/grammar) | Búsqueda por palabra clave, navegación alfabética y explicaciones desplegables. |
| [Historial de consultas](https://lingfern.com/library/history) | Reabrir consultas de diccionario, uso e IPA con fuente, hora y estado guardado. |

Elige Cambridge, Oxford Learner’s Dictionaries, Wiktionary o Merriam-Webster para búsquedas externas. Los enlaces abren el sitio del proveedor; los de uso emplean Cambridge Grammar.

<a id="readme-offline"></a>

## Recursos sin conexión y comunitarios

Busca, selecciona, instala, actualiza o elimina paquetes de texto, audio y referencia en Biblioteca. Con los recursos necesarios instalados, aprendizaje, corrección, guardado y referencias instaladas funcionan sin conexión. Los cambios de conexión muestran un aviso breve.

Importa ZIP comunitarios compatibles y conserva los originales para reinstalar o cambiar de dispositivo. Descargas, GitHub, MCP y sitios externos requieren conexión; los recursos y audios se instalan en cada dispositivo.

Si tu navegador lo permite, instala Lingfern o añádelo a la pantalla de inicio para usarlo como aplicación web.

<a id="readme-backup"></a>

## Perfiles y copias de seguridad

Cambia de perfil en **Ajustes → Copia de seguridad**. Exporta un ZIP con `lingfern-YYYY-MM-DD` o un nombre propio; también se guarda dentro como nombre del perfil restaurado. Renombrar el archivo ZIP no cambia ese nombre interno.

Revisa nombre y número de registros antes de importar como perfil separado. Eliminar un perfil local exige confirmación; otros perfiles y las copias del repositorio remoto se conservan.

Las copias incluyen sesiones, respuestas, borradores, marcadores, historial, comentarios y preferencias. **No están cifradas** y excluyen paquetes/audio instalados: guárdalas en privado y reinstala los recursos por separado.

<a id="readme-sync"></a>

## Sincronización automática con GitHub

1. Conecta GitHub desde Ajustes y selecciona un perfil de la cuenta o copia el local a ella.
2. Crea un repositorio de datos dedicado **privado**, autoriza la GitHub App y selecciona/verifica el repositorio en la configuración.
3. La sincronización bidireccional intercambia resúmenes de aprendizaje, marcadores, historial, preferencias, elecciones de instalación y eliminaciones compatibles. Los cambios sin conexión esperan la reconexión.

La tarjeta muestra sincronizando, sincronizado, pendiente sin conexión o error y la última sincronización correcta. Usa **Sincronizar ahora / Reintentar**, pausa el modo automático o desvincula el repositorio en la configuración. Los conflictos pueden exportarse cuando aparezca la recuperación. No se transfieren sesiones completas, respuestas ni audio instalado: usa copias de seguridad para todos los registros.

**Desconectar identidad de GitHub** cierra las sesiones en todos los dispositivos, desactiva las vinculaciones de sincronización, elimina los elementos compartidos activos y revoca las conexiones MCP. Los registros locales y archivos del repositorio permanecen. Sigue las instrucciones si no se confirma la revocación en GitHub. También puedes revocar un elemento o conexión MCP sin desconectar la identidad.

<a id="readme-ai"></a>

## Transferencia a IA y MCP

- En respuestas guardadas compatibles, selecciona objetivo, material/extracto, pregunta, respuesta y comentarios. Previsualiza, copia, exporta Markdown/JSON o usa el uso compartido del sistema cuando exista. Pega/importa los comentarios recibidos, revísalos y guárdalos aparte; respuestas y puntuaciones originales no cambian.
- Conecta un cliente **Streamable HTTP + OAuth** a `https://lingfern.com/mcp` y comparte explícitamente una instantánea con esa conexión. Caduca a las **24 horas** o antes si caduca la conexión. Gestiona/revoca clientes y elementos compartidos en Ajustes. Los clientes autorizados buscan/leen sus instantáneas y, con un permiso distinto, buscan resúmenes de materiales públicos. [Configuración y herramientas (inglés)](mcp-clients.md).

<a id="readme-preferences"></a>

## Idioma y apariencia

Catorce idiomas; tema claro/oscuro/sistema; navegación de texto, iconos o mixta independiente para móvil/escritorio; diccionario externo predeterminado; puntos de partida e intereses modificables; teclado, pantalla táctil y reducción de movimiento.

Los materiales ingleses permanecen en inglés. Las instrucciones revisadas A1–A2 cuentan con traducción; B1–C2 y About siguen en inglés. La navegación árabe es RTL y el contenido inglés LTR.

**Buscar actualizaciones → Actualizar ahora** recarga conservando el progreso guardado. About y los detalles del material muestran enlaces del proyecto, fuentes y licencias.

<a id="readme-privacy"></a>

## Datos y privacidad

Los registros permanecen en el almacenamiento del sitio de este navegador. Exporta una copia antes de borrar datos o cambiar de dispositivo. GitHub es opcional y su sincronización no sustituye una copia completa.

Sin publicidad ni telemetría activada por defecto. La IA solo recibe contexto seleccionado/compartido, no el historial privado. Revocar no borra copias ya recibidas por otro servicio. Los resultados describen el desempeño en tareas, no un nivel MCER certificado ni una nota de examen.

## Ejecución local y contribuciones

Usa la versión Node.js de [`.nvmrc`](../.nvmrc) y ejecuta desde la raíz:

```sh
npm ci
npm run build
npm run preview
```

Abre la [vista previa local](http://127.0.0.1:8787/today). El aprendizaje local no necesita credenciales de GitHub/Cloudflare.

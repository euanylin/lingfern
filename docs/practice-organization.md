## Generation and source limits

`src/core/practiceOrganization.ts` owns effort configuration and organisation. It runs after existing eligibility/rights/exclusion/hold/history/seed/two-root/focus selection and before the new snapshot is returned. Existing primary semantic questions stay intact. The existing generator hash includes this module. All additional question IDs are stable source-coordinate identifiers;the final strict schema rejects duplicates and unsupported evidence.

The reading planner uses the requested word bands,level-dependent time budgets,useful restoration sentences,paragraph count,lexical complexity,explicit relationship markers,numeric facts and title/topic-derived genre signals. These are transparent effort heuristics,not calibrated CEFR/IELTS ability estimates. Word bands (<250:3–6;250–499:6–10;500–899:10–16;≥900:14–24) are references. Complexity reduces the target,structure/explicit information raises it,and duplicated sentences count once. Level effort caps run from9minutes(A1) to30(C2),with35minutes/32groups as defensive upper bounds;rich long texts can exceed a reference band. At most12additional restoration questions are selected,with no obligation to fill the target. Candidate extraction precedes bounded selection. Exact-source word completions use unique target words,one sentence per question,paragraph-spreading passes and original source offsets. Event/year tables reuse the existing validated date extractor. Skip the complete primary/additional evidence ranges of other objective questions and cross-question answer cues. A whole-passage unscored reflection does not mean every detail has already been objectively tested. Retain existing reviewed semantic/inference/main-point/discourse frames;no unsupported inference templates are added. Low-information sources may remain below the planning range;more words alone never guarantee more questions.

Listening keeps the existing installed/qualified clip and exact hashes. Additional multi-gap groups require matching source text,audio hash/duration and retained clip segment alignments. Select no more than one target per aligned segment,with unique source words and no overlapping existing objective evidence. Spacing uses source word rate,audio duration,level-related support and input allowance;the bounded initial reference is based on the maintainer's8–12second suggestion. It is not an official IELTS timing rule. Compare the previous segment's end with the next segment's start;never pretend those segment limits are word timestamps. The full extract is reconstructed byte-for-byte when answers are substituted,retaining sentence/context structure. Short audio or insufficient trustworthy separated segments produces fewer/no extra gaps. No time-stretching,padding,new recordings or fabricated timing data is introduced.

Personal-record deletion clears workspace drafts as well as original drafts/annotations. Legacy single-question APIs reject material-workspace sessions so they cannot accidentally produce a partial sequential completion. Required source/score/history/recovery/security assertions remain.

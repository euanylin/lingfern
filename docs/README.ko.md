**[웹사이트 ↗](https://lingfern.com)**

<img src="../public/icon.svg" width="96" alt="Lingfern">

## 시작하기

1. [Lingfern](https://lingfern.com)의 소개를 보고 시작 수준과 관심사를 설정합니다.
2. [오늘](https://lingfern.com/today)에서 **읽기·듣기·통합 연습**을 고르고 미리보기에서 **연습／테스트**를 시작합니다. 통합 연습은 읽기와 듣기 세션을 연결해 저장합니다.
3. [자료실](https://lingfern.com/library)에서 조회·다운로드하고, [설정](https://lingfern.com/settings)에서 환경 설정·프로필·선택적 연결을 관리합니다.

<a id="readme-practice"></a>

## 연습과 테스트

읽기와 듣기의 목표 수준, 주제, 자료, 문제 유형을 각각 지정하거나 **자동**을 사용합니다. 선택은 프로필별로 저장됩니다. 자료에 따라 선택형, 빈칸, 근거 선택, 짝짓기, 표, 순서 배열, 서술형 문제가 제공됩니다.

| 모드 | 동작 |
|---|---|
| 연습 | 제공되는 학습 예시, 3단계 힌트(목표·단서·언어), 사전, 자기 평가. |
| 테스트 | 동일한 연습 자료에서 도움과 AI를 끄고 완료 후 피드백을 표시합니다. 오디오 재생·탐색은 가능합니다. |

객관식 문제에는 유형별 채점과 해설이 제공되며, 서술형은 자동 채점하지 않습니다. **건너뛰기／답변 재개**는 초안을 보존하고 건너뛴 답을 정답으로 처리하지 않습니다.

<a id="readme-workspace"></a>

## 읽기·듣기 조작

- 원문의 단어를 선택해 사전 조회·강조 표시를 하고 자료 메모를 저장합니다.
- 답안 카드는 문제 위치만 이동하며 입력을 자동으로 시작하지 않습니다. 모바일 읽기는 답안 패널 펼치기·크기 조절, 데스크톱은 두 영역의 독립 스크롤을 지원합니다.
- 현재 녹음의 모든 문제 묶음과 하위 문제를 순서대로 표시합니다. 일시 정지·다시 재생·탐색·문제 이동 시 재생 상태와 초안을 유지합니다.
- 작성 중 초안이 저장됩니다. 마지막 문제 뒤에서 제출하거나 미완료 연습을 이어 할 수 있고, 확인 후 **다시 시작**으로 세션을 교체할 수 있습니다. 저장 실패 시 페이지를 떠나기 전에 안내된 재시도·복구·초안 내보내기를 이용하세요.

<a id="readme-history"></a>

## 기록과 진도

오늘의 [**기록**](https://lingfern.com/progress)에서 세션, 답안, 피드백, 사용한 도움을 확인하고, 확인 후 저장된 답을 삭제할 수 있습니다. 읽기·듣기 목표별 진도를 보고, 시각 보정 항목이 나타나면 완료 시각을 확인할 수 있습니다.

고사리는 저장된 학습 활동을 나타내며 공인 실력을 뜻하지 않습니다. 오늘의 인용문에는 출처, 긴 글 펼치기, 다른 문장 선택 기능이 있습니다.

## 조회 도구와 북마크

| 도구 | 기능 |
|---|---|
| [영영사전](https://lingfern.com/library/dictionary) | 단어를 찾아 영어 뜻 확인 및 읽기 중 선택한 단어 조회. |
| [북마크](https://lingfern.com/library/saved) | ★／☆로 뜻 저장·해제, 항목 접기. 해제한 항목은 다시 열거나 새로고침하기 전까지 남아 즉시 복원할 수 있습니다. |
| [IPA 발음표](https://lingfern.com/library/ipa) | 간단／상세 보기, 발음 기호 검색, 제공되는 녹음과 영어 예시 단어. |
| [영어 용법 사전](https://lingfern.com/library/grammar) | 키워드 검색, 알파벳 탐색, 설명 펼치기. |
| [조회 기록](https://lingfern.com/library/history) | 출처·시각·저장된 조회 상태에 따라 사전·용법·IPA 조회를 다시 엽니다. |

외부 사전은 Cambridge, Oxford Learner’s Dictionaries, Wiktionary, Merriam-Webster 중 선택할 수 있습니다. 해당 제공자의 사이트에서 열리며, 용법 링크는 Cambridge Grammar를 사용합니다.

<a id="readme-offline"></a>

## 오프라인·커뮤니티 자료

자료실에서 글·오디오·조회 자료 묶음을 검색·선택·설치·업데이트·제거합니다. 필요한 자료가 설치되면 학습, 채점, 저장, 설치된 조회 도구를 오프라인에서 사용할 수 있습니다. 연결 변화는 잠시 상태 알림으로 표시됩니다.

호환되는 커뮤니티 ZIP을 가져올 수 있습니다. 재설치와 다른 기기를 위해 원본 ZIP을 보관하세요. 다운로드, GitHub, MCP, 외부 사이트는 인터넷이 필요하며 자료와 녹음은 기기마다 설치합니다.

지원하는 브라우저에서는 앱 설치／홈 화면에 추가 기능으로 웹 앱처럼 사용할 수 있습니다.

<a id="readme-backup"></a>

## 프로필과 백업

**설정 → 백업**에서 프로필을 전환합니다. 기본 `lingfern-YYYY-MM-DD` 또는 직접 입력한 이름으로 ZIP을 내보냅니다. 이 이름은 복원할 프로필 이름으로 내부에도 저장되므로 외부 ZIP 이름을 바꿔도 내부 이름은 달라지지 않습니다.

이름과 기록 수를 미리 확인한 뒤 별도 프로필로 가져옵니다. 로컬 프로필 삭제는 확인이 필요하며 다른 프로필과 원격 저장소 사본은 유지됩니다.

백업에는 세션, 답안, 초안, 북마크, 조회 기록, 피드백, 환경 설정이 포함됩니다. **암호화되지 않으며**, 설치된 자료 묶음·오디오는 포함하지 않습니다. 안전하게 보관하고 자료는 따로 설치하세요.

<a id="readme-sync"></a>

## GitHub 자동 동기화

1. 설정에서 GitHub에 연결한 뒤 계정 프로필을 선택하거나 로컬 프로필을 복사합니다.
2. 전용 **비공개** 데이터 저장소를 만들고 GitHub App에 권한을 부여한 뒤 설정 중 저장소를 선택·검증합니다.
3. 학습 요약, 북마크, 조회 기록, 환경 설정, 설치 선택, 지원되는 삭제를 자동 양방향 동기화합니다. 오프라인 변경은 재연결까지 보존됩니다.

동기화 중·동기화 완료·오프라인 대기·실패 상태와 마지막 성공 시각을 표시합니다. **지금 동기화／재시도**, 자동 동기화 일시 중지, 설정 중 저장소 연결 해제가 가능합니다. 충돌 복구 항목이 나타나면 데이터를 내보낼 수 있습니다. 전체 세션·답안·설치된 오디오는 동기화하지 않으므로 전체 기록은 백업으로 옮기세요.

**GitHub 신원 연결 해제**는 모든 기기의 사이트 세션을 종료하고 동기화 바인딩을 비활성화하며 활성 공유를 제거하고 MCP 연결을 취소합니다. 로컬 기록과 저장소 파일은 유지됩니다. GitHub 측 취소를 확인할 수 없으면 화면 안내를 따르세요. 신원 연결을 유지한 채 개별 MCP 공유나 연결만 취소할 수도 있습니다.

<a id="readme-ai"></a>

## AI 전달과 MCP

- 지원되는 저장 답안에서 목표, 자료／발췌, 문제, 답, 피드백을 선택합니다. 미리 본 뒤 복사, Markdown／JSON 내보내기, 지원 기기의 시스템 공유를 사용할 수 있습니다. 받은 피드백을 붙여 넣거나 가져와 검토 후 별도로 저장하며 원래 답과 점수는 변경하지 않습니다.
- **Streamable HTTP + OAuth** 호환 클라이언트에 `https://lingfern.com/mcp`를 추가하고 해당 연결에 스냅샷을 명시적으로 공유합니다. 공유는 **24시간** 또는 더 이른 연결 만료 시 끝나며 설정에서 공유·클라이언트를 관리·취소합니다. 권한을 받은 클라이언트는 공유된 스냅샷을 검색·읽고, 별도 권한으로 공개 자료 요약을 검색할 수 있습니다. [클라이언트 설정과 도구(영어)](mcp-clients.md).

<a id="readme-preferences"></a>

## 언어와 화면

14개 UI 언어, 밝게／어둡게／시스템 테마, 데스크톱·모바일 각각의 글자·아이콘·혼합 탐색, 기본 온라인 사전, 시작 수준·관심사 변경, 키보드·터치·동작 줄이기 설정을 지원합니다.

영어 자료는 영어로 유지됩니다. 검토된 A1–A2 안내에는 번역이 제공되고 B1–C2 안내와 About은 영어입니다. 아랍어 탐색은 RTL, 영어 내용은 LTR로 표시합니다.

**업데이트 확인 → 지금 업데이트**는 저장한 진도를 유지하며 새로고침합니다. About과 자료 상세에 프로젝트 링크, 출처, 라이선스가 있습니다.

<a id="readme-privacy"></a>

## 데이터와 개인정보

기록은 현재 브라우저의 사이트 저장소에 보관됩니다. 사이트 데이터를 지우거나 기기를 바꾸기 전에 백업하세요. GitHub 동기화는 선택 사항이며 전체 백업을 대신하지 않습니다.

광고나 기본 활성화된 원격 측정은 없습니다. AI는 명시적으로 선택·공유한 문맥만 받고 개인 전체 기록을 읽지 않습니다. 취소해도 외부 서비스가 이미 받은 사본은 삭제할 수 없습니다. 결과는 과제 수행을 설명할 뿐 공인 CEFR 등급이나 시험 점수가 아닙니다.

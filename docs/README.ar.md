## البدء

1. افتح [Lingfern](https://lingfern.com)، واطّلع على المقدمة، ثم اختر مستويات البداية والاهتمامات.
2. في [اليوم](https://lingfern.com/today)، اختر **القراءة** أو **الاستماع** أو **التدريب المدمج**، ثم **التدريب** أو **الاختبار** من المعاينة. يحتفظ التدريب المدمج بجلستَي قراءة واستماع مترابطتين.
3. استخدم [المكتبة](https://lingfern.com/library) للمراجع والتنزيلات، و[الإعدادات](https://lingfern.com/settings) للتفضيلات والملفات الشخصية والاتصالات الاختيارية.

<a id="readme-practice"></a>

## التدريب والاختبار

حدّد مستوى الهدف والموضوعات والمواد وأنواع الأسئلة للقراءة والاستماع كلٍّ على حدة، أو أبقِ **تلقائيًا**. تُحفظ الاختيارات لكل ملف شخصي. بحسب المادة، تتوفر أسئلة اختيار، وإكمال فراغات، واختيار أدلة، ومطابقة، وجداول، وترتيب، وإجابات مفتوحة.

| الوضع | السلوك |
|---|---|
| التدريب | أمثلة وثلاثة تلميحات (الهدف، الدليل، اللغة) وقاموس وتقييم ذاتي عند توفرها. |
| الاختبار | التمرين نفسه دون مساعدة أو ذكاء اصطناعي؛ تظهر الملاحظات بعد الإكمال. تبقى إعادة تشغيل الصوت والتنقل فيه متاحتين. |

تُقيَّم الأسئلة الموضوعية مع شروح مناسبة. لا تُقيَّم الإجابات المفتوحة آليًا؛ يحتفظ **تخطَّ السؤال / استأنف الإجابة** بالمسودة دون اعتبار التخطي إجابة صحيحة.

<a id="readme-workspace"></a>

## أدوات القراءة والصوت

- حدّد نصًا للبحث في القاموس أو تمييزه، واحفظ ملاحظات على المادة.
- تنقلك بطاقة الإجابات إلى السؤال دون بدء الكتابة تلقائيًا. يمكن توسيع لوحة إجابات القراءة وتغيير حجمها على الهاتف؛ وتتحرك اللوحتان باستقلال على الحاسوب.
- تُعرض جميع مجموعات وأسئلة التسجيل الحالي بالترتيب. يحتفظ الإيقاف المؤقت والإعادة والتنقل في الصوت وبين الأسئلة بحالة التشغيل والمسودات.
- تُحفظ المسودات أثناء الإجابة. أرسل بعد السؤال الأخير، أو استأنف جلسة غير مكتملة، أو أكّد **البدء من جديد** لاستبدال الجلسة. إذا تعذّر الحفظ، استخدم إعادة المحاولة أو الاستعادة أو تصدير المسودة قبل المغادرة.

<a id="readme-history"></a>

## السجل والتقدم

افتح [**السجل**](https://lingfern.com/progress) من اليوم لمراجعة الجلسات والإجابات والملاحظات والمساعدات المستخدمة، ولحذف إجابات محفوظة بعد التأكيد. راجع تقدم أهداف القراءة والاستماع، وأكّد أوقات الإكمال عند ظهور خيار تصحيح الساعة.

تعبّر السرخسة عن النشاط المحفوظ، لا عن مستوى معتمد. تشمل الاقتباسات اليومية المصدر، وتوسيع النص الطويل، واختيار اقتباس آخر.

## المراجع والإشارات المرجعية

| الأداة | الوظائف |
|---|---|
| [قاموس إنجليزي](https://lingfern.com/library/dictionary) | البحث عن الكلمات وتعريفاتها بالإنجليزية، بما فيها الكلمات المحددة أثناء القراءة. |
| [الإشارات المرجعية](https://lingfern.com/library/saved) | حفظ التعريف أو إزالته باستخدام ★/☆ وطيّ المدخل. يبقى المدخل المُزال حتى إعادة الفتح أو التحديث لتتمكن من إعادته فورًا. |
| [جدول IPA](https://lingfern.com/library/ipa) | عرض مبسط أو تفصيلي، وبحث عن الأصوات، والتسجيلات والكلمات الإنجليزية التوضيحية المتاحة. |
| [مرجع استعمال الإنجليزية](https://lingfern.com/library/grammar) | بحث بالكلمات المفتاحية، وتصفح أبجدي، وشروح قابلة للتوسيع. |
| [سجل البحث](https://lingfern.com/library/history) | إعادة فتح عمليات البحث في القاموس والاستعمال وIPA مع المصدر والوقت وحالة البحث المحفوظة. |

اختر Cambridge أو Oxford Learner’s Dictionaries أو Wiktionary أو Merriam-Webster للبحث الخارجي. تفتح الروابط موقع المزوّد، وتستخدم روابط الاستعمال Cambridge Grammar.

<a id="readme-offline"></a>

## موارد دون اتصال وموارد المجتمع

ابحث عن حزم النصوص والصوت والمراجع وحدّدها وثبّتها أو حدّثها أو أزلها من المكتبة. بعد تثبيت الموارد المطلوبة، يعمل التعلّم والتقييم والحفظ والمراجع المثبتة دون اتصال. يظهر إشعار قصير عند تغيّر حالة الاتصال.

يمكن استيراد ملفات ZIP مجتمعية متوافقة. احتفظ بالأصل لإعادة التثبيت أو لجهاز آخر. تحتاج التنزيلات وGitHub وMCP والمواقع الخارجية إلى اتصال؛ وتُثبَّت الموارد والتسجيلات على كل جهاز على حدة.

إذا كان المتصفح يدعم ذلك، استخدم تثبيت التطبيق أو الإضافة إلى الشاشة الرئيسية لتشغيل Lingfern كتطبيق ويب.

<a id="readme-backup"></a>

## الملفات الشخصية والنسخ الاحتياطية

بدّل الملفات الشخصية في **الإعدادات ← النسخ الاحتياطي**. صدّر ZIP بالاسم المقترح `lingfern-YYYY-MM-DD` أو باسم تختاره؛ ويُحفظ الاسم داخله أيضًا ليكون اسم الملف الشخصي المستعاد. لا تغيّر إعادة تسمية ملف ZIP الاسم الداخلي.

عاين الاسم وعدد السجلات قبل الاستيراد في ملف شخصي مستقل. يتطلب حذف ملف شخصي محلي تأكيدًا؛ وتبقى الملفات الأخرى والنسخ الموجودة في المستودع البعيد.

تشمل النسخ الجلسات والإجابات والمسودات والإشارات وسجل البحث والملاحظات والتفضيلات. وهي **غير مشفّرة** ولا تشمل حزم الموارد أو الصوت المثبتة: احفظها بشكل خاص وأعد تثبيت الموارد منفصلة.

## مزامنة GitHub التلقائية

1. صِل GitHub من الإعدادات، ثم اختر ملفًا شخصيًا للحساب أو انسخ ملفك المحلي إليه.
2. أنشئ مستودع بيانات مخصصًا **خاصًا**، وامنح GitHub App الوصول، ثم اختر المستودع وتحقق منه أثناء الإعداد.
3. تتبادل المزامنة الثنائية ملخصات التعلّم والإشارات وسجل البحث والتفضيلات واختيارات التثبيت وعمليات الحذف المدعومة. تُحفظ التغييرات دون اتصال إلى أن يعود الاتصال.

تعرض البطاقة المزامنة الجارية أو المكتملة أو الانتظار دون اتصال أو الفشل ووقت آخر نجاح. استخدم **زامن الآن / أعد المحاولة**، أو أوقف المزامنة التلقائية مؤقتًا، أو افصل ارتباط المستودع أثناء الإعداد. يمكن تصدير البيانات المتعارضة عند ظهور الاستعادة. لا تنقل المزامنة الجلسات الكاملة أو الإجابات أو الصوت المثبت؛ استخدم نسخة احتياطية لنقل السجلات الكاملة.

ينهي **فصل هوية GitHub** جلسات الموقع على جميع الأجهزة، ويعطّل ارتباطات المزامنة، ويحذف المشاركات النشطة ويلغي اتصالات MCP. تبقى السجلات المحلية وملفات المستودع. اتبع تعليمات الشاشة إذا لم يتأكد إلغاء التفويض لدى GitHub. ويمكن أيضًا إلغاء مشاركة أو اتصال MCP منفرد دون فصل الهوية.

<a id="readme-ai"></a>

## تسليم السياق للذكاء الاصطناعي وMCP

- للإجابات المحفوظة المدعومة، اختر الهدف والمادة أو المقتطف والسؤال والإجابة والملاحظات. عاين ثم انسخ أو صدّر Markdown/JSON أو استخدم مشاركة النظام عند توفرها. ألصق الملاحظات المستلمة أو استوردها وراجعها واحفظها منفصلة؛ لا تتغير الإجابات والدرجات الأصلية.
- صِل عميلًا يدعم **Streamable HTTP + OAuth** بالعنوان `https://lingfern.com/mcp`، ثم شارك لقطة صراحة مع ذلك الاتصال. تنتهي بعد **24 ساعة** أو قبل ذلك إذا انتهى الاتصال. أدِر المشاركات والعملاء أو ألغِها في الإعدادات. يستطيع العميل المصرّح له البحث في لقطاته وقراءتها، وبإذن منفصل البحث في ملخصات المواد العامة. [إعداد العملاء والأدوات (بالإنجليزية)](mcp-clients.md).

## اللغة والمظهر

أربع عشرة لغة للواجهة؛ سمة فاتحة أو داكنة أو تبعًا للنظام؛ تنقل بالنص أو الرموز أو كليهما بإعداد مستقل للهاتف والحاسوب؛ قاموس خارجي افتراضي؛ تعديل مستويات البداية والاهتمامات؛ دعم لوحة المفاتيح واللمس وتفضيل تقليل الحركة.

تبقى المواد الإنجليزية بالإنجليزية. تتوفر ترجمة للإرشادات المراجعة في A1–A2؛ وتبقى إرشادات B1–C2 وصفحة About بالإنجليزية. التنقل العربي من اليمين إلى اليسار، والمحتوى الإنجليزي من اليسار إلى اليمين.

تعيد **التحقق من التحديثات ← تحديث الآن** تحميل الصفحة مع الاحتفاظ بالتقدم المحفوظ. تعرض About وتفاصيل المواد روابط المشروع والمصادر والتراخيص.

<a id="readme-privacy"></a>

## البيانات والخصوصية

تبقى السجلات في تخزين الموقع بهذا المتصفح. صدّر نسخة قبل مسح بيانات الموقع أو تغيير الجهاز. GitHub اختياري، والمزامنة لا تعوّض نسخة احتياطية كاملة.

لا توجد إعلانات أو قياسات استخدام مفعّلة افتراضيًا. يحصل الذكاء الاصطناعي فقط على السياق المحدد أو المشارك صراحة، لا السجل الخاص. لا يحذف الإلغاء نسخًا تلقّتها خدمات أخرى. تصف النتائج أداء المهام، لا مستوى CEFR معتمدًا أو درجة امتحان.

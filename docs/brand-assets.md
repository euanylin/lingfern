# Lingfern symbol

The single source artwork is [public/icon.svg](../public/icon.svg): the green fern symbol used by the application, its authorisation pages and the project documentation.

The application displays this same SVG as a CSS mask in the theme's accent colour. Its geometry stays unchanged in light and dark themes. The PNG files [icon-192.png](../public/icon-192.png) and [icon-512.png](../public/icon-512.png) are size-specific installation icons, not alternative logo designs.

When authorised to use the artwork, preserve its complete outline and square proportions. Leave clear space around it. Do not stretch, crop, redraw or combine it with replacement lettering. Use a meaningful accessible label when the symbol conveys the project identity; decorative copies beside labelled links can be hidden from assistive technology.

The artwork is covered by the separate [brand policy](../BRAND.md), rather than automatically by the software or documentation licence.

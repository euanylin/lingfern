# Lingfern

**[網站 ↗](https://lingfern.com)**

<img src="../public/icon.svg" width="96" alt="Lingfern">

## 開始使用

1. 開啟 [Lingfern](https://lingfern.com)，瀏覽介紹並設定學習起點與興趣。
2. 在[今日](https://lingfern.com/today)選擇**閱讀、聽力或綜合訓練**，於預覽選擇**練習或測試**；綜合訓練保存相互關聯的閱讀與聽力練習。
3. 在[資料庫](https://lingfern.com/library)查詢、下載資源；在[設定](https://lingfern.com/settings)管理偏好、檔案與選用連線。

<a id="readme-practice"></a>

## 練習與測試

分別設定閱讀與聽力的目標等級、主題、材料及題型，或保留**自動**。選擇依檔案保存。題型依材料而定，包括選擇、填空、證據選擇、配對、表格、排序和開放回答。

| 模式 | 行為 |
|---|---|
| 練習 | 提供適用的教學示例、三級提示（目標、線索、語言）、詞典與自評。 |
| 測試 | 使用同一練習快照，關閉輔助與 AI，完成後顯示回饋；保留音訊重播和進度跳轉。 |

客觀題提供對應評分與解釋；開放回答不自動評分。**跳過此題／繼續作答**保留草稿，不將跳過計為正確。

<a id="readme-workspace"></a>

## 閱讀與聽力操作

- 閱讀原文，選詞查詢或標示重點，保存材料筆記。
- 答題卡只定位題目，不自動進入輸入；行動版閱讀可展開、調整答題面板大小，桌面版兩欄可獨立捲動。
- 聽力依原順序顯示目前錄音的全部題組、小題；暫停、重播、拖動進度或跳題時保留播放與草稿。
- 作答時自動保存草稿；最後一題後提交，也可繼續未完成練習，或確認**重來**以替換練習。保存失敗時，離開前使用提示的重試、復原或草稿匯出功能。

<a id="readme-history"></a>

## 歷史紀錄與進度

從今日進入[**歷史紀錄**](https://lingfern.com/progress)，回看練習、答案、回饋與輔助使用情況，確認後刪除已保存的回答；查看閱讀、聽力目標進度，出現時鐘修正選項時確認完成時間。

活動蕨反映已保存的學習活動，不代表認證程度。每日一句標明來源，長文可展開，也可切換另一句。

## 查詢工具與書籤

| 工具 | 功能 |
|---|---|
| [英英詞典](https://lingfern.com/library/dictionary) | 依詞查閱英語釋義，也可在閱讀中選詞查詢。 |
| [書籤](https://lingfern.com/library/saved) | 用 ★／☆ 保存、取消釋義，摺疊詞條；取消後的詞條在重開或重新整理前保留，方便立即復原。 |
| [IPA 發音表](https://lingfern.com/library/ipa) | 簡易／詳細檢視、音標搜尋，以及可用的音標錄音和英語例詞。 |
| [英語用法詞典](https://lingfern.com/library/grammar) | 關鍵字搜尋、字母瀏覽、展開解釋。 |
| [查詢歷史](https://lingfern.com/library/history) | 依來源、時間與保存的查詢狀態，重新開啟詞典、用法與 IPA 紀錄。 |

可選擇 Cambridge、Oxford Learner’s Dictionaries、Wiktionary 或 Merriam-Webster 進行線上查詢。連結於對應網站開啟，用法查詢使用 Cambridge Grammar。

<a id="readme-offline"></a>

## 離線與社群資源

在資料庫搜尋、選擇、安裝、更新或移除文章、音訊與查詢資源套件。安裝所需資源後，學習、評分、保存與已安裝的查詢工具均可離線使用；連線變化有短暫狀態提示。

可匯入相容的社群 ZIP 材料／資源套件；保留原始 ZIP，方便重裝或換裝置。下載、GitHub、MCP 和外部網站需要連線；資源與錄音須在各裝置分別安裝。

在支援的瀏覽器中，可透過「安裝應用程式／加入主畫面」將 Lingfern 作為網頁應用程式使用。

<a id="readme-backup"></a>

## 檔案與備份

在**設定 → 備份**切換檔案。匯出時可使用預設的 `lingfern-YYYY-MM-DD` 名稱或自訂名稱；名稱也保存在備份內部，供還原後的檔案使用。手動改 ZIP 檔名不會覆蓋內部名稱。

匯入前預覽檔案名稱與紀錄數量，還原為獨立檔案。刪除本機檔案須確認，其他檔案與遠端儲存庫副本保留。

備份包含練習、答案、草稿、書籤、查詢歷史、回饋與偏好，**未加密**，不含已安裝的資源套件／音訊；請妥善保管，並另外重裝資源。

<a id="readme-sync"></a>

## GitHub 自動同步

1. 在設定連接 GitHub，選擇帳號檔案，或複製本機檔案至該帳號。
2. 建立專用的**私有**資料儲存庫，為 GitHub App 授權，在設定過程中選擇並驗證儲存庫。
3. 自動雙向同步學習摘要、書籤、查詢歷史、偏好、安裝選擇及支援的刪除操作；離線修改保留，連線後補傳。

卡片顯示同步中、已同步、離線待同步或失敗及上次成功時間；可**立即同步／重試**、暫停自動同步，或在設定中解除儲存庫綁定。出現衝突復原選項時，可匯出衝突資料。同步不傳輸完整練習、答案或已安裝音訊，完整紀錄請使用備份。

**斷開 GitHub 身分**會結束所有裝置的網站工作階段、停用同步綁定、移除有效分享並撤銷 MCP 連線，保留本機紀錄和儲存庫檔案。若無法確認 GitHub 端撤銷，請依頁面提示操作；也可在不斷開身分的情況下單獨撤銷 MCP 分享或連線。

<a id="readme-ai"></a>

## AI 交接與 MCP

- 對支援的已保存回答，選擇目標、材料／節選、題目、回答及回饋，預覽後複製、匯出 Markdown／JSON，或在支援的裝置使用系統分享。貼上或匯入返回的回饋，審閱後另存；原答案與分數不變。
- 在相容的 **Streamable HTTP + OAuth** 用戶端連接 `https://lingfern.com/mcp`，再明確向該連線分享快照。分享於 **24 小時**或更早的連線到期時失效，可在設定管理、撤銷分享與用戶端。授權用戶端可搜尋、讀取其分享快照，另獲相應權限後可搜尋公開材料摘要。見[用戶端設定與工具（英文）](mcp-clients.md)。

<a id="readme-preferences"></a>

## 語言與外觀

14 種介面語言；淺色／深色／跟隨系統主題；桌面與行動版分別選擇文字、圖示或圖文導覽；預設線上詞典；可調整學習起點與興趣；支援鍵盤、觸控及減少動態效果偏好。

英語材料保持英文。經審查的 A1–A2 指導提供翻譯支援，B1–C2 指導及關於頁面保持英文。阿拉伯語導覽由右至左排列，英語內容維持由左至右。

**檢查更新 → 立即更新**重新整理頁面並保留已保存進度。關於與材料詳情提供專案連結、來源及授權。

<a id="readme-privacy"></a>

## 資料與隱私

紀錄保存在目前瀏覽器的網站儲存空間，清除網站資料或換裝置前請匯出備份。GitHub 同步是選用功能，不能取代完整備份。

無廣告、不預設收集遙測資料。AI 僅能取得明確選取或分享的上下文，不能讀取私人歷史；撤銷無法刪除其他服務已接收的副本。結果反映任務表現，不是認證 CEFR 等級或考試分數。

## 本機執行與參與專案

使用 [`.nvmrc`](../.nvmrc) 指定的 Node.js 版本，在儲存庫根目錄執行：

```sh
npm ci
npm run build
npm run preview
```

開啟[本機預覽](http://127.0.0.1:8787/today)。本機學習無需 GitHub／Cloudflare 憑證。

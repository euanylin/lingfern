# Lingfern licensing proposal — local review only

**DRAFT — NOT ADOPTED OR PUBLISHED.** On2026-10-18 the maintainer authorized preparation of this local proposal:Apache-2.0 for project software,CC BY4.0 for documentation/original non-code content,attribution naming Lingfern with its project link,and separate brand/logo treatment. That authorization does not adopt these grants,assert ownership of third-party material,or authorize a repository,commit,push,upload,deployment,DNS change or public launch. The main package metadata and root licensing state are unchanged.

## Proposed scope

The following applies only to copyright and other rights the relevant Lingfern contributors control. A file's location or its inclusion in an export does not establish ownership. Existing specific notices and third-party terms take precedence for their material;no existing hold is relaxed.

| Material | Proposed treatment |
|---|---|
| Lingfern-authored program logic,build/preparation tools,tests,styles and functional configuration in `src/`,`worker/`,`scripts/`,`tests/`,`.github/` and root build files | Apache License2.0;retain existing author/source notices. This does not relicense incorporated third-party code or non-code material |
| Lingfern-authored documentation and original non-code prose,including original interface/instructional/explanatory copy | CC BY4.0;the code containing a string remains separately covered as software. This does not claim ownership of quoted passages,translations of third-party works or other externally sourced text |
| Existing dependencies,vendored licence files,NOTICEs,external dictionaries,source passages/quotations,audio,transcripts,fonts,models and generated outputs governed by separate terms | Their actual per-source/per-component terms and precise holds remain;no blanket Apache/CC relabelling. Public-domain material gains no new restriction from this proposal |
| Lingfern name,wordmark,symbol,logo/brand SVGs,signature artwork and derived brand icons | Separate [brand proposal](BRAND.proposed.md);no automatic Apache/CC artwork grant |
| Private learner/research data,credentials,private evidence,original acquisitions and backups | No new publication permission;excluded from public-source upload. Ordinary project snapshots exclude private evidence,credentials and browser/remote data |

This is a scope declaration for the project-controlled contributions,not a new audit of unchanged sources. Reuse the retained source/rights records and all precise holds. The 72 teaching cells and existing multilingual copy are not reopened by preparing this proposal.

## Attribution proposal

Project name: **Lingfern**. Canonical project link: **https://lingfern.com**. This is the project identifier;the current domain is not claimed to be a deployed service. The proposed GitHub source location is not yet created or published.

For covered software,retain the applicable copyright,licence and attribution notices and supplied NOTICE as Apache2.0 requires. The proposed NOTICE preserves Lingfern and its project link as informational attribution;it does not add a UI badge,advertising,approval,commercial-use restriction or a new licence condition.

For covered documentation/original non-code material,the designated attribution is **Lingfern contributors**,with the project link and applicable licence;identify modifications and preserve supplied relevant notices. A practical example is:

> Based on Lingfern by Lingfern contributors — https://lingfern.com — CC BY4.0: https://creativecommons.org/licenses/by/4.0/ . Changes: describe the changes made.

Use attribution in a manner reasonable for the medium under the actual licence. The example is not mandatory wording or a claim of endorsement. Do not apply it in place of a third-party author/source credit.

# Lingfern brand policy proposal — local review only

**DRAFT — NOT ADOPTED OR PUBLISHED.** This is the separate brand/artwork section of the [local licensing proposal](README.md). No trademark registration,exclusive ownership beyond established rights,worldwide uniqueness or permission to relicense third-party artwork is asserted.

The proposed software Apache2.0 and documentation/original-content CC BY4.0 grants do not automatically cover the copyright in `logo/*.svg`,`public/logo/*.svg`,`public/icon.svg`,`public/icon-192.png`,`public/icon-512.png`,or `Signature/*.svg`. File copies/derived icons retain the corresponding artwork scope. The logo guide's prose is documentation;the artwork it describes remains separate. The existing source publication allowlist includes only its explicitly selected signature file;this document adds no other signature assets to that list.

Proposed trademark treatment:retain Lingfern's name and project link in applicable attribution and permit reasonable,truthful reference to the project's origin. Do not imply endorsement,official status or ownership of a derivative project. These statements do not remove rights granted by Apache2.0,CC BY4.0 or applicable exceptions;they do not introduce mandatory advertising or a restriction on otherwise licensed code.

Art reproduction/modification permissions beyond existing authorized project use remain **ungranted pending separate final approval**. Public visibility or an approved source upload would not itself grant a general artwork licence. This draft does not prohibit uses permitted by law,and it does not require permission to make the attribution the software/content licences allow. It does not impose new obligations retroactively.

When authorized to display the original assets,follow the existing asset guide (`logo/README.md`; local reference, excluded from public copy):use the supplied complete SVG,retain geometry/proportions/descenders and do not redraw or crop it. Actual SVG,signature and icon bytes are unchanged. No new artwork,font,brand registration or external permission request is introduced.

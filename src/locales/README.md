# Language packages

[Lingfern](https://lingfern.com)

Each language has its own directory: `zh-Hans/`, `zh-Hant/`, `en/`, `ja/`, `ko/`, `fr/`, `es/`, `de/`, `pt/`, `it/`, `ru/`, `ar/`, `hi/`, `id/`. `messages.json` contains interface namespaces and the language's native display name. Components read an existing namespace with `messages('taskDetail')[locale]`; do not add language switches or translated text to components. Add the same key/shape to every package. Translate each key in context: navigation “History” and the school subject “History” intentionally use different terms. `tests/locales.test.ts` checks completeness and placeholders.

Package maintenance uses Codex/AI content review, key and placeholder completeness, layout, offline and saved-record checks. Record the actual reviewer and inspected text; historical provenance remains unchanged.

Use named placeholders such as `{count}` and pass values to `messages`. Values are substituted literally, never executed or interpreted as HTML. Keep quotation text, names, URLs, author credits, actual licence names and learner input intact. Dates and relative dates use the browser's `Intl` implementation with the selected locale.

Japanese, Korean, French, Spanish, German, Portuguese, Italian, Russian, Arabic, Hindi and Indonesian also have `teaching.json`: 353 inspected English instruction frames mapped to display translations (324 original frames, four dynamic helpers and 25 previously uncovered runtime explanations). `{v0}` etc. preserve exact source/answer values. More specific frames match before general ones; tests exercise every frame and literal replacement characters. Nine explicitly inspected explanation slots may translate nested instruction text, bounded to two template levels; all other slots remain literal source/answer values. Extend all eleven packages together only after checking the complete source meaning, source/answer roles and each translation. Do not translate source passages or scoring data.

Saved/generated curriculum content retains its original validated three-language shape and hashes. Simplified/Traditional Chinese use the translations saved in that snapshot; English uses its original English. `contentText` supplies the available display translations for known A1/A2 frames without rewriting records. Unknown/private/older instructional text falls back to the original English and receives an English language tag. This is intentional fallback, not an automatic machine-translation service. B1–C2 instructions always request English via `practiceLocale`, including old snapshots. General controls remain localized.

`src/shared/locale.ts` owns supported codes and browser language negotiation. Both Settings and First Run use the same native-name options. Explicit saved choices take precedence over browser preferences. Settings, sync validation and ZIP backup restore accept all fourteen supported codes; unknown codes are rejected. Original three-language content schemas remain unchanged for compatibility.

All packages remain in the application build and existing Service Worker precache. Additional teaching JSON is evaluated on demand through `loadInstructionLocale`;await it before displaying or saving a changed locale. Failed loading retains the current locale;FirstRun releases its busy state. Sync/backup loading also awaits the selected package before showing records. There is no translation server, separate language installation, added localization dependency, source picker or required account. The app continues teaching English; selecting a display language changes interface/help, not the target learning language.

All eleven additional languages provide reviewed A1–A2 instructional display frames. These are display languages, not new target-language courses. Arabic sets the root `dir="rtl"`; explicit English content stays LTR and isolated. Layout uses logical text alignment/margins/padding; the existing physical right-edge drawer and popup-arrow geometry remain unchanged. Native language labels use `bdi` with their actual language. Test any added RTL language before changing `localeDirection`.

About is always English. Its own title, back link, credits and contact labels live in `../app/aboutCopy.ts`, outside language packages. `About` accepts no display-language prop and sets `lang="en" dir="ltr"`. Do not add About-page translations to current or future packages. Keep the Settings About entry and surrounding navigation localized. Source names, licences, artwork and learning snapshots are unchanged.

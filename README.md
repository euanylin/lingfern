# Lingfern

[Website](https://lingfern.com) · [English](README.md) · [简体中文](docs/README.zh-CN.md) · [User guide](docs/user-guide.md)

<img src="public/icon.svg" width="96" alt="Lingfern">

English reading and listening practice, online or offline. For learners aged 16 and over, with learning goals from A1 to C2. No account or AI service is required to learn.

## What you can do

| Feature | Included |
|---|---|
| **Reading, Listening and Combined** | Generate practice locally from source texts and recordings. Set goals, interests, topics, materials and question types; Combined runs reading followed by listening. |
| **Practice and Test** | Use examples, three hints, dictionary support and self-assessment in Practice. Test keeps assistance off and reveals feedback after completion. Objective answers are scored; open responses can be skipped and remain unscored. |
| **Reading and audio controls** | Highlight passages, save material notes, locate questions with the answer card, and scroll through all questions for the current recording. Audio supports pause, replay and seeking. |
| **Saved work** | Resume drafts, revisit answers and feedback, delete saved responses, and view reading/listening progress and the activity fern. Today also offers daily quotations. |
| **Reference tools** | English dictionary, collapsible bookmarks, simple/full IPA charts with recordings, English usage reference and query history across all three reference tools. Choose an external dictionary for online lookup. |
| **Offline resources** | Search, install, update or remove resource packs in Library. Import compatible community ZIPs with their text and audio. |
| **Profiles and backups** | Switch or delete local profiles; name and export a backup ZIP, preview it and restore it as a separate profile. |
| **Automatic GitHub sync** | Connect a private data repository to exchange learning summaries, bookmarks, query history, preferences and installation choices. Includes offline pending changes, sync status and manual retry. |
| **Optional AI handoff** | Preview and export selected context as Markdown/JSON, save returned feedback separately, or share a time-limited snapshot with an authorised MCP client. Manage shares and revoke access in Settings. |
| **Personalisation** | Fourteen interface languages, light/dark/system themes, separate desktop/mobile navigation display, starting-point and interest settings, app updates and source/licence credits. |

Start at [lingfern.com](https://lingfern.com): **Today** for training and History, **Library** for references and downloads, **Settings** for preferences and connections. See the [user guide](docs/user-guide.md) for instructions.

Supported interface languages: Simplified Chinese, Traditional Chinese, English, Japanese, Korean, French, Spanish, German, Portuguese, Italian, Russian, Arabic, Hindi and Indonesian. English material stays in English; A1–A2 guidance has translated support. B1–C2 guidance and About use English. Arabic navigation supports RTL.

## Your data

Learning records are stored in your browser. Export backups before clearing site data or moving devices: ZIPs are unencrypted and exclude installed resource packs and audio. GitHub sync is optional and does not replace a full backup. MCP clients receive only explicitly shared snapshots; revoking access cannot erase copies already received. Lingfern has no advertising or default telemetry.

Learning results describe task performance, not a certified CEFR level or examination score.

## Run locally and contribute

Follow the [development guide](docs/development.md) for installation, local preview and checks. Report bugs or suggest improvements through [GitHub Issues](https://github.com/euanylin/lingfern/issues); keep private records and credentials out of attachments.
